# figures/

Code for every scripted figure panel. All data are read from `results_final/` and `data/`;
no number is typed into a figure script.

```bash
python3 figures/run_all.py              # all panels
python3 figures/run_all.py fig3 figS9   # only scripts whose name starts with these
```

Each script in `panels/` draws one panel and saves SVG, PDF and PNG (600 dpi) to
`output/<Figure>/`. The script names follow the numbering used while the analysis was
developed. `run_all.py` therefore also copies each panel to `paper/` under its label in
the manuscript, using the table below. The final figures were assembled from these panels
in Inkscape.

`common.py` holds the palette, the clade groups and the data loaders shared by all panels.
`cuag_tree()` calls the tree-matching function of `scripts/final_analysis.py`, so Fig. 1d
always shows the same tree as the report.

## Folders

| Folder | Content |
|---|---|
| `panels/` | one script per panel |
| `standalone/` | scripts that read `data/` directly (Figs S2, S3) or the PyMOL site tables (Fig. 5) |
| `output/` | every panel under its script name (generated, not tracked by git) |
| `paper/` | the panels under their manuscript labels (generated) |
| `pymol/` | PyMOL colouring scripts, per-site tables and colour bars (generated by step 7 of `run_all.sh`) |
