
# alphafold/

AlphaFold 3 models of the human proteins used for the structure panels (Figs 2f, 3b and 5).
The models are not generated by this repository; place them here as

```
alphafold/
├── aqp1/channel.pdb   aqp1/tail.pdb
├── aqp2/channel.pdb   aqp2/tail.pdb
├── aqp4/channel.pdb   aqp4/tail.pdb
├── aqp5/channel.pdb   aqp5/tail.pdb
├── aqp6/channel.pdb   aqp6/tail.pdb
└── aqp8/channel.pdb   aqp8/tail.pdb
```

- `channel.pdb`: the channel (core) protein, residues numbered as in the human reference
  sequence (AQP4 1-323, NM_001650.7).
- `tail.pdb`: the read-through extension, the peptide encoded downstream of the canonical
  stop codon, numbered from 1 (AQP4: residue 1 = human residue 325).

PDB format is needed for the numbering check (convert AlphaFold's mmCIF output, e.g. with
PyMOL `save model.pdb`).

## How the models are used

`run_all.sh` (step 7) runs `scripts/fel_to_pymol.py` for every gene and region. When a
model is present here, the script checks that its residues match the human sequence at
each number (at least 90% must match) and writes a PyMOL script that loads it. Without a
model it still writes the script, which then colours an object named after the gene that
you load yourself:

```
pymol alphafold/aqp4/tail.pdb
PyMOL> set_name tail, aqp4
PyMOL> @figures/pymol/aqp4_tail_omega.pml
```

| Panel | PyMOL script (in `figures/pymol/`) |
|---|---|
| Fig. 2f, conservation of the AQP4 extension | `aqp4_extension_conservation.pml` (from `scripts/seqlogo.py`) |
| Fig. 3b, site-wise ω on the AQP4 extension | `aqp4_tail_omega.pml` |
| Fig. 5, α and β on channel and tail of each gene | `<gene>_{channel,tail}_{alpha,beta}.pml` |

The colour scales are fixed and identical for every gene and region, so the panels can be
compared directly; the colour bars are written as `figures/pymol/colorbar_<quantity>.png`.
